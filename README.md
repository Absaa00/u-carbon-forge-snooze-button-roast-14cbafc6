# Snooze Button Roast

[![make.fun](https://make.fun/badge.svg)](https://make.fun)

Entry for the make.fun competition
[Snooze Button Roast](https://make.fun/competitions/u-carbon-forge-snooze-button-roast-14cbafc6).

`main.py` writes one line to `/output/entry.txt`: a roast of an alarm clock
that rings at 6 AM on a Saturday morning. Deterministic, no network,
no input — the same line on every run.

Run it:

```sh
python3 main.py
```
